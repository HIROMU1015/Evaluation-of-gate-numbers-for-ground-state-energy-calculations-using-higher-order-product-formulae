# GPU側で行う追加検証

## 現在の結論（2026年9月2日）

資料作成に必要なH9〜H11の有限時間診断は、m5とMorales Y8m10bの両方についてコミット `e935f21` で完了している。H6/H7の細分化した直接境界も同じ系サイズ予測へ統合して再集計した。

現在の共通予測規則では、m5のH5予測は $t_{\mathrm{pass}}$ と $t_{\mathrm{fail}}$ の間にあり未確定、Y8m10bのH7予測は $t_{\mathrm{fail}}$ より後にあり不合格となった。このため、両PFの現時点の分類は「短時間・漸近参照のみ」であり、H9〜H11のコストへ確定した時刻上限 $t_{\mathrm{cap}}$ はまだ使えない。

| 検証項目 | 状態 | 資料での扱い |
|---|---|---|
| H9〜H11の短時間次数と係数 | 完了 | 短時間モデルの根拠に使う |

再集計結果は `artifacts/server_cost_validity/integrated_boundary_recheck_20260902/` に保存している。既存の未加工JSONは上書きしていない。

## 今すぐ追加GPU計算を行わない理由

H9〜H11では、両PFとも $0.5t_{\mathrm{ana}}$ で重なり位相誤差がモデルの10%以内、$0.7t_{\mathrm{ana}}$ で10%範囲外となることまで確認できている。しかし、これらは直接PF固有値誤差ではない。

m5についてはH5の予測時刻を1点直接計算すれば未確定を解消できる。一方、Y8m10bの上限規則は未使用サイズ検証に明確に不合格なので、いまH9〜H11の点を増やしても「検証済み上限」にはならない。したがって、Y8m10bでは追加GPU計算より先に新しい共通上限規則を固定する必要がある。

## 次に行う検証

### 1. 新しい共通上限規則を事前に固定する

新しい規則はm5とY8m10bで共通とし、数式、入力データ、許容差を計算前に文書化する。現在のH5〜H7結果を見て調整した係数は探索値と明記し、それだけで「検証済み」とは扱わない。

最低限、次を固定する。

- $t_{\mathrm{pass}}$ の系サイズ依存性に使う関数形。
- 安全側補正係数の求め方。
- 10%境界が区間でしか分からない場合に、合格側の $t_{\mathrm{pass}}$ と不合格側の $t_{\mathrm{fail}}$ のどちらを使うか。
- $t_{\mathrm{cap}}\le t_{\mathrm{pass}}$ は安全側、$t_{\mathrm{pass}}<t_{\mathrm{cap}}<t_{\mathrm{fail}}$ は予測時刻を直接計算して再判定、$t_{\mathrm{cap}}\ge t_{\mathrm{fail}}$ は不合格とすること。

### 2. 新規則を独立な系で検証する

H2〜H7を見て規則を作り直すなら、同じH2〜H7だけを再度合格判定に使うことはできない。次のどちらかを独立検証に用いる。

1. H8で基底状態へ接続するPF固有位相を近似し、直接計算に近い10%境界を求める。
2. H-chain以外の追加分子・構造で直接PF固有値誤差を計算し、固定済み規則が安全側になるか調べる。

追加分子による検証は化学構造をまたぐ移行性を調べるもので、H-chainの系サイズ外挿を直接証明するものではない。この違いは資料にも明記する。

### 3. H8近似法を使う場合の合格条件

現在の反復部分空間法は、H6のY8m10b/m5コスト比について直接値1.538に対し0.938〜1.002となり、相対差が約35〜39%ある。10%基準を満たしていないため、現状のままH8の根拠には使えない。

改良する場合は、H6/H7で次をすべて満たしてから、方法と設定を固定してH8へ適用する。

- 各PFの近似固有対の残差を出す。
- 部分空間次元と数値打ち切り値を変えた収束性を示す。
- 時刻方向の連続性と厳密基底状態との重なりで同じ固有枝を追う。
- 各PFの誤差とY8m10b/m5コスト比を直接値の10%以内で再現する。

### 4. 直接検証を通過した後だけH9〜H11を細分化する

固定した上限規則が独立検証を通過した場合に限り、H9〜H11について予測 $t_{\mathrm{cap}}$ とその前後を計算する。まず $0.5t_{\mathrm{ana}}$ と $0.7t_{\mathrm{ana}}$ の既存結果を境界区間として使い、予測上限がこの区間内にある場合だけ2〜3点を追加する。

追加点では、補正後の $e_{\mathrm{ov}}/e_{\mathrm{model}}$、生存確率、$C_{\mathrm{ov}}/C_{\mathrm{model}}$ を出す。ただし、重なり位相を直接PF固有値誤差と同一視しない。

## 必要な出力

- 実行条件、基準コミット、回路・PFラベル、時刻、補正前後の複素重なりを含むJSON。
- $t_{\mathrm{pass}}$、$t_{\mathrm{fail}}$、予測 $t_{\mathrm{cap}}$、安全側補正係数を含む集計JSON。
- 各条件の合格・不合格と最終分類を自動集計したMarkdown。
- 完了していない項目や失敗した項目も削除せず、「不合格」または「未検証」として残す。

最終分類は、資料中では次の日本語に統一する。

- 有限時間の絶対推定を支持
- 時刻上限制約付きの感度推定
- 短時間・漸近参照のみ
