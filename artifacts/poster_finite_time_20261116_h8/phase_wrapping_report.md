# H8追加監査：位相折り返しとPF誤差

観測された重なり低下を一律に「セクター幅による最初の折り返し2π/W」と置く仮説は支持されない。一方、実際に混ざる相手をPF固有ベクトルから調べると、個別のエネルギー差による1周目または2周目の位相一致に対応する例が多い。10%適合域を失う原因を、すべてこの共鳴で説明することもできない。
基準commitは5e006b5。既存成果物は変更せず本報告を追加。作図用結果JSONはphase_wrapping_analysis.jsonの1個（49,782 bytes、50 KB以下）。

H4・8次の10%逸脱は主候補の割合が約61%で、相手は一意に同定できない。最初の重なり低下点では別のk=35（Emax）が支配的で約2周目に近い。

## H8・10次の条件付き最小値

重なり≥0.99かつシフトの枝照合差≤1e−10 Ha、コスト定義可能な保存点に限定。296点中93点が合格し、最小は許容保存点の上端：

- t=2.419038862603172、重なり=0.992559189753。
- 総回転数=786550122.488988161、同条件の8次最小=533360933.280892789。
- 10次/8次=1.474705163820。8次最小は条件内側。
- 次の保存点t=2.419047260646646は重なり=0.971489023で除外。

「上端での値」であり、保存した許容点集合にはこれより低い値はない。ただし未計算の連続時刻の最小値の下限とは言えず、追加点で下がる可能性がある。
厳密な下限が必要ならt≤t_cap=2.419038862603172に範囲を固定し、e≥0よりF≥βN/(t_cap ε_E)=701824547.528367043を使える。この下限の8次比は1.315852931356>1。ただしcap以降に再び条件を満たす未計算点がないとは主張しない。
条件付き最小値のための新規対角化は0点。前報1.3158は不一致の最小点を含む参考値で、今回の条件付き1.4747と区別して前報を保存する。
