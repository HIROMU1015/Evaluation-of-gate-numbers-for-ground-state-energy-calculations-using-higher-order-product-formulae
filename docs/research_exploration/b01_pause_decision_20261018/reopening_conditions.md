# B-01：新証拠と再開判断の条件

正式状態は `PAUSED_PENDING_NEW_EVIDENCE`。以下はユーザー承認済みの再開判断条件の例であり、今回の調査・計算・新アルゴリズム探索の発注ではない。

- 条件付きmomentの正規化誤差、confidence、必要標本費について、従来の判断を変える具体的な数学的結果。
- 合法なseedとHamiltonian familyに対し、取得・検証費を含め有用なground重み下界etaを保証する証拠。
- 同じD1 accessとsoundness・completenessを維持し、強い既知手法との差を生む具体的な生成規則または費用命題。

既知法にも同じ合法情報・精度・confidence・費用範囲を与える。単なる名称・係数・角度の変更、標準統計の組合せ、未確認資料の存在、未実装という事実だけで独立新機構としない。証拠取得費を0にせず、D1/D2を無断変更しない。

新証拠が提示されても自動再開しない。**GPT／ユーザー**が旧判断との差と再開対象を判断し、**ユーザー**が範囲を承認する。重要科学レビュー、科学計算、実装の実行承認は別である。**Codex**は別途承認された範囲だけを扱い、既存SOURCE・契約・STOPを上書きしない。

今回のPhase Bは既存成果の状況整理であり、この条件に該当する新証拠を探す作業ではない。
