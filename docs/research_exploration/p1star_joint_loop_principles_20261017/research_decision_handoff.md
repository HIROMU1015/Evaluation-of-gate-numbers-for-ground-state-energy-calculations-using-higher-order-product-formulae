## 1. 保持した問い

**J1：CARで結び付く二つの交換経路から、一つの共同閉路を作る。** 4軌道について

\[
Q_1=E_{pq}E_{rs},\qquad Q_2=E_{ps}E_{rq},\qquad
Q_1+Q_2=0,\quad Q_1-Q_2=2Q_1.
\]

このfull FockのCAR関係を構成前の入力とし、2次信号には差を、3次の不要なbus作用には和を割り当てる制御cellがあるかを問う。元の失敗にあった、未完了の変位による相互作用の共役を、別経路との共同相殺へ変える狙いである。

保持理由は、必要な二体信号と不要作用を異なるCAR部分へ分ける具体的な代数的関係と、実pathに対する判別条件を記述できたこと。最大の障害は、**式の交換が物理的なpath変換ではなく、2次面積と3次モーメントを独立に割り当てられないこと**。この持上げが未解決なので高リスクとして保持し、成立済みとはしない。

J1は元のL1/L2だけに制御を限定しない。仮説本文のHermitianな軌道hopping factorとそのphase成分への共通X/P結合が必要で、追加accessと費用は未確立。4 primitive・12 segment・振幅boxを変更したscience jobは実施していない。

## 2. 最初に検証すべきこと

**最初は四軌道の交換対1個について、CAR交換関係を実制御pathへ持ち上げられるかを紙上で判別する。** 全Hamiltonianの係数生成、solver、新しい固定wordの大量探索から始めない。

| 確認項目 | 必要な結果 |
| --- | --- |
| 実操作 | Hermitian一体factor×bus X/Pの実制御だけでcellを記述。非Hermitian Eの指数や二体oracleを使わない。 |
| 低次信号 | 1次が零、2次が非零のHermitianなdouble excitation×bus Iになる。全ての不要bus 2次も消える。 |
| 3次 | X/P一次だけでなく、次数3のWeyl成分と全電子body数まで零化する。CAR交換関係が不可欠なことを示す。 |
| pathの整合性 | iterated integralのshuffle関係、logのLie条件、実係数／Hermiticityを満たす。面積と3次係数を独立な変数として扱わない。 |
| 独立性の第一点検 | 比較用の普遍包絡代数では非零の3次bus項がCARで零になる。既知の目標gateにCAR-nullなidentity cellを付け足しただけの例は除く。既知の完成閉路＋汎用echo／DCGへ説明全体が還元される場合は、独立仮説として取り下げる。 |

正の結果は「CARによる3次相殺を実現する局所文法がある」という限定知見になる。**それでも4次整合、有限時間の帰還、一般の化学係数・複素位相への拡張、資源改善は未確立**。段階を飛ばして正式採択しない。

負の結果は、どの持上げ条件が二体信号を消すか、どのprimitive不足が原因かを明らかにする。個別cell又は有限wordの失敗だけでは、全ての共同閉路やP1*一般の不可能性としない。
