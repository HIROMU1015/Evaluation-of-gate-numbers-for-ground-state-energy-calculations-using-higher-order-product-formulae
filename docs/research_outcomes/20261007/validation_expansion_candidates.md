**H6でSlide 11と同じ短時間比較を行う案は、H4の結果の適用範囲を確かめる候補になる。** ただし、短時間の原因比較を増やすこと、長時間の予測が外れる理由を調べること、QPE予算を改善することは、それぞれ別の問いである。以下ではこの違いを保って整理する。

## 2. 新しい科学計算なしで先に整理できる事項

資料上のコメントには、追加検証ではなく保存結果で回答できるものもある。

- **H4の状態品質：** RHFの厳密状態との重なり²は0.9364638564、CISDは0.9994668439。人工状態の前に示せる。状態差は各入力状態と厳密状態の代理量の差であり、CISDだけを指す量ではない。
- **正負時刻の診断：** H4の56ケースについて、正時刻の四次・六次モデル、正負平均の四次・六次モデル、奇数成分の五次・七次診断の計168モデルが保存されている。結果が本文で省略されていても、未実施ではない。
- **一項モデルの費用差：** Slide 6の約0.168%・0.172%は、一項モデルが選んだ点の直接費用と、その周囲の保存点での直接最小費用との差。二項モデルの同時刻での費用予測誤差と分けて説明できる。
- **HFの不足量：** 同じPF・時刻に必要な余裕倍率は保存された直接必要費用／予測費用から事後計算できる。ただし、その値を知って新しい余裕規則を決めても独立検証にはならない。
- **既存の別鎖対照：** H6には長時間の状態改善・三成分の結果がある。しかし、Slide 11と同じ固定短時間・人工状態56ケースの比較ではない。

代理量と元論文の摂動評価の関係、CISDを選択入力に使う理由も、既存の定義・実装・情報アクセス条件を確認して説明する事項である。説明への追記は今回行わず、ユーザーが加えたスライド注記を保持する。

### A1：Slide 11の短時間比較をH6へ広げる

**問い：同じ固定時刻・同じ判定で、H6でも状態差が三成分の中で支配するか。** H4とH6の件数を別々に示し、H4の49/56を全体系へ一般化しない。

- H6直線鎖、原子間距離1.0 Å、STO-3G、中性一重項。既存追加検証の400次元の入力を再利用する。以前のH6/H7 holdoutの200次元とは区別する。
- PFはYoshida4、基準PF、予測重視PF、追加候補Cの4種類。RHF・CISDに、CISD残差方向へ混ぜる12状態を加えた14状態。厳密状態は別の比較基準とする。
- fit時刻の大きさは0.10、0.15、0.20、0.25、0.30。評価は0.125、0.175、0.225、0.275、0.35、0.40。正負とも計算し、主モデル・正負診断・数値gate・多数決と3倍の分類をH4から継承する。
- 4PF×14状態＝56ケース、評価は56×12＝672行。異なるPF・時刻の座標は4×22＝88で、cold repeatはこの数に含めない。上限案は各座標2回のPF構築、計176回。backend、状態への作用の数え方、真値評価の呼出上限と壁時計上限は実行前に固定する。

人工状態を作るために厳密状態を使う**原因分析**であり、未知問題で使う予測手順の独立検証ではない。低信号・fit不能・枝不成立も分母とともに保存し、結果を見て時刻域や分類閾値を変えない。短時間の結果だけでは長時間の予算問題は閉じない。

実行の材料は比較的揃っている。H6の既存私有入力ファイルは存在とファイルhashの一致を確認したが、今回配列の再読込・状態生成は行っていない。既存H6の401点直接評価では各PFの保存実行時間が約98–235秒、BLAS 1 thread、最大RSS約0.50 GiBだった。これは別の処理内容・実行環境の記録であり、A1の所要時間へ比例換算しない。

### A2：長時間のモデル差について、小さな項数比較を行う

H4・追加候補Cに絞り、保存された同じ5 fit時刻のCISDと厳密状態の代理量を、四次＋六次と四次＋六次＋八次でfitする案。2状態×2モデルの4 fitとし、元の選択点2.1466061015と直接候補最小点3.5175172133で、予測と直接代理量の差を比べる。PF・評価時刻・元の予算は変えない。

新しいPF作用なしで試せる可能性があるが、**新fit自体は追加承認の対象**である。係数の識別性・条件数・残差を報告する。八次項を加えて改善しても、係数推定・打ち切り・外挿を一意に分離したとは言えない。fit窓を変更する比較は、この4 fitとは別に時刻と停止条件を決める。

F01/F02では既にH2/H4×4PFの有効HamiltonianのD4/D6/D8と、a8の状態混合を調べている。今回の候補の問いは、**現在の長時間の代理量予測**への項数の効果であり、「八次項の機構は未検証」とは扱わない。F02では小さい相殺後係数の識別性が問題となった条件もある。

### A3：別鎖の1点で、代理量の固有成分を分ける

H6・追加候補Cの保存直接最小点2.2834071119880326で、厳密状態の代理量をPF固有成分の和へ分解する案。保存された点ごとの判定では`branch_reliable=True`である。必要ならA1と共通の0.40を比較点として別途指定し、最大2点に限定する。

追跡成分・他の成分・重みの合計・代理量の和の一致・正弦の線形近似差を保存する。H6の元選択点3.0391925965は正式分類未確認なので、そこで得た最大重なり成分を正式な対応固有値へ置き換えない。保存判定で評価可能な1点での結果は、選択点までの対応を新たに確定することや、全鎖に共通する機構の証明とは区別する。

### A4：H5またはH6の枝の不成立を診断する

最初の段階は新規対角化ではなく、保存されたground overlap・previous overlap・数値残差を並べること。追加候補Cの最初の不成立点では、H5の重なり²は約0.891と0.823、H6は約0.859と0.841で、いずれも既存基準0.9を下回った。**時刻を細かくするだけで基底状態への対応条件も満たせるとは限らない。**

H5は50次元、H6は400次元。どちらか1条件の元選択点を固定し、不成立区間を事前指定した点数上限で細分する案は作れる。ただし、縮退部分空間の追跡、対応の定義、追加時刻、停止上限を先に決める必要があり、まだ実行仕様になっていない。新しい診断を正式分類へ採用するかは研究判断である。既存の未確認分類は保持し、閉じなかった結果もそのまま残す。

### A5：H4の人工状態へ、もう一つの混入方向を加える

既存のCISD残差方向に加え、RHFから厳密基底状態成分を除いた正規化残差方向を使う案。同じq＝0.1%、1%、5%、相対位相4通り、4PF、元の固定時刻を使う。追加は48ケース・576評価行。方向間の重なりも示し、二方向がほぼ同じなら独立した方向の検証として数えない。

H4の36次元で実施できる。異なる方向での状態感度を確かめられるが、実用的な状態改善やSlide 23の診断規則の改善を直接示す比較ではない。

### A6：保存最小費用点の周りだけを細分する

H4・追加候補Cの401点の最小点と両隣の時刻を固定し、最小点から左右それぞれの隣点までを4等分した9点で比べる案。元の候補は対数刻みなので、左右の間隔は同じとは限らない。両端・元の最小点の3点は既存で、異なる新規時刻は6点になる。元の枝・数値gate・費用式を使い、元の候補最小費用と新しい局所最小費用を別に示す。

これは候補の刻みの診断であり、連続時間全体の最適性を保証しない。Slide 6のH6/H7の局所7点を細分する案もあるが、別の入力・protocolなので、一つの実験へ混ぜずに選ぶ。

### A7：未使用条件で、凍結した手順を独立に評価する

目的は分子一般性・選択手順の汎化である。まず未使用の分子または構造を1条件選び、PF集合、fit時刻規則、時刻上限、余裕倍率、状態生成、truth access、計算上限を結果を見る前に固定する。対象が未選択なので、次元・点数・計算時間はまだ見積もれない。

開発6条件に新しい閾値を合わせても独立検証にはならない。第2研究には既存のprospective validationがあるので、そちらの対象・結果を先に確認し、第1研究の手順を追加評価する目的と区別する。新条件を大量に追加する前に、何を一般化したいかを決める必要がある。

### A8：既存follow-upの2×2比較の準備を閉じる

N₂/CO平衡で、CISD/Ritz8と短時間fit/選択時刻の直接代理量評価を分ける既存設計を参照する。PFとQPEに使う時刻t₀を固定し、校正入力と情報取得場所の介入を比較する。QPEに使う入力状態まで変更する効果とは分ける。

参照した公開snapshot `9accc300ba7b8049ae9a1ef870ca4e7c0032e6ae`では、**`NO_GO_FOR_FS_C1`、`science_authorized=false`**。元baselineは3 fit時刻と0.5倍のsentinelで、設計案の「元5点」と一致しない。入力配列のcanonical identity、native backendの精度・費用会計・実行上限も未確定である。最初の作業はこの準備の整合確認であり、欠けた入力を再生成したり比較科学計算を開始したりしない。

## 4. どの目的なら、どの候補を検討するか

| 広げたい範囲 | 対応する候補 | この選び方の意味 |
|---|---|---|
| 今のスライドの結果を、別の鎖でも確かめたい | A1 | Slide 11に最も直接対応。H4/H6を同じ短時間条件で比べる |
| 長時間で予測が外れる理由を詳しくしたい | A2、A3 | モデル差と代理量差を、それぞれ別の比較で調べる |
| 別鎖の正式分類の未確認を減らしたい | A4 | 物理的対応の設計が先。成功を保証できない |
| 近似状態への感度の範囲を広げたい | A5 | 既存の一つの混入方向に依存した結果かを調べる |
| 数値的な候補最小費用の頑健性を確認したい | A6 | 少数点で可能。ただし誤差機構や資源改善方法とは別 |
| 独立条件への一般化を主張したい | A7 | 対象と凍結手順を先に選ぶ必要がある |
| 実際のQPE予算を改善する介入を調べたい | A8 | 既存follow-upに接続。現在は準備段階 |

技術的な進め方の案は、保存値の整理を先に済ませ、選んだ候補だけをbounded protocolにすること。A1を選ぶなら、同じH6入力を使うA3との共通処理を検討できるが、実行範囲の承認は分ける。「時間が空いているから全部実行する」という範囲にはしない。

GPTに判断してほしいのは、**既存の結果の適用範囲を広げるのか、長時間の機構を詳しくするのか、資源判断の改善へ進むのか**、その目的に合う候補はどれか、結果がどちらに出ても研究の次の判断に使えるかである。研究上の必要性・優先順位は本資料だけでは決定しない。
